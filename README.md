# Subtract-two-numbers-50


Subtract Two Numbers

Description

This is a simple HTML and JavaScript program that subtracts two numbers and displays the result in an alert box.

The program uses the numbers 7 and 3 and calculates their difference:

7 - 3 = 4

How It Works

1. Open the HTML file in a web browser.
2. The page displays a "Subtract two numbers" heading and a short description.
3. Click the "Press Here" button.
4. The JavaScript "subtract()" function is called.
5. The program subtracts "3" from "7".
6. An alert displays:

The difference is : 4

Technologies Used

- HTML5
- CSS3
- JavaScript

Code Structure

The program contains:

- An HTML page for the user interface.
- CSS to set the background color and font.
- A JavaScript "subtract()" function to perform the calculation.
- A button that calls the function when clicked.

Running the Program

Save the code as an HTML file, for example:

index.html

Then open "index.html" in any modern web browser.

Example Output

When the Press Here button is clicked, the following message appears:

The difference is : 4
